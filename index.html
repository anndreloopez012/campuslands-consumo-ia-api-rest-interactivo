01
Fundamentos · RA 1

¿Qué es una API y por qué la usamos con la IA?

Una API (Application Programming Interface) es un conjunto de reglas para que dos programas conversen. Tu app no entra a la base de datos de nadie ni instala el modelo: pide algo siguiendo las reglas y recibe una respuesta.

Ejemplo de todos los días

Una app del clima no tiene estación meteorológica: le pregunta a un servicio del clima por su API. Con la IA es igual: tu app envía una instrucción a un servicio que ejecuta un LLM (modelo de lenguaje de gran escala) y recibe el resultado.

REST, en una frase

REST es un estilo para diseñar APIs: cada recurso tiene una URL, se usan métodos estándar (GET, POST…) y cada solicitud lleva todo lo necesario (sin estado).

Ojo: POST /responses es una API HTTP de inferencia. Se parece a REST, pero no cumple todos sus principios. En la guía usamos ambos términos y señalamos la diferencia.

Juego: ¿quién hace qué?

Arrastra o toca cada tarea y luego toca el componente que la hace.

Autenticación · RA 6

La API Key es un gafete, no una contraseña para el modelo

La clave identifica y autoriza a tu aplicación. Viaja en el encabezado Authorization: Bearer TU_API_KEY. Quien la tenga puede gastar a tu nombre, por eso vive en una variable de entorno del servidor.

Inspector del navegador

Cualquier persona puede abrir las herramientas de desarrollo (F12) y ver lo que envía una página. Compara.

ElementsConsoleNetworkSources

Sí

  • Guardar la clave en OPENAI_API_KEY (variable de entorno).
  • Usar el gestor de credenciales de n8n.
  • Agregar .env al .gitignore.
  • Usar HTTPS y validar lo que llega al backend.

Nunca

  • Escribirla en el código JavaScript del navegador.
  • Subirla a Git, capturas de pantalla o ejemplos públicos.
  • Dejarla escrita en comandos que queden en el historial.
  • Mandarla dentro del prompt al modelo.

Para que no te sorprenda

Una suscripción a ChatGPT y el uso de la API son servicios distintos. La API se factura por uso: modelo, tokens procesados y otros recursos.

# 2. Verificar que existe, sin imprimir su valor
if [ -n "$OPENAI_API_KEY" ]; then
    echo "Clave configurada"
else
    echo "Falta configurar la clave"
fi

La respuesta · RA 4

Leer el JSON: dónde está el texto y cuánto costó

JSON (JavaScript Object Notation) representa información con propiedades y valores. Con él viajan la instrucción, los parámetros del modelo y el resultado.

Taller de JSON en vivo

Escribe o corrige el objeto. Te decimos si es válido y qué tipo tiene cada valor.

Misión: encuentra el texto generado

Esta respuesta trae dos elementos en output. Toca valores del árbol; cuando toques el texto que escribió el modelo, ganas la misión. Debajo verás cómo llegar a ese dato en jq, Python y JavaScript.

Nunca supongas que output[0] es el mensaje: filtra por type == "message" y luego por type == "output_text".

Ruta del dato Toca un valor

Cada propiedad tiene una función: id, status, model, output, usage…

Control de errores · RA 6

Cuando algo falla: leer el código y decidir

Tu app depende de un servicio remoto: puede fallar la conexión, la clave, la cuota o el servidor. No basta con programar el camino feliz.

Toca un código

Elige un código HTTP

Te diremos qué significa y si conviene reintentar.

Simulador de reintentos (exponential backoff)

Cada espera es el doble que la anterior. En la vida real se suma un poco de azar (jitter), un máximo de intentos y se respeta Retry-After.

    Cuidado: una solicitud de generación pudo haberse procesado aunque no recibiste la respuesta. Reintentar a ciegas puede cobrarte dos veces.

    Error HTTP

    El servicio devuelve un código de fallo como 401, 429 o 500.

    Error funcional

    Llegó un 200, pero el texto no tiene el formato esperado o status no es completed. Un 200 no garantiza una buena respuesta.

    Consumo y costos

    Tokens: el taxímetro del modelo

    Un token es la unidad con la que el modelo procesa texto. No es lo mismo que una palabra: puede ser una palabra, un pedazo de ella o un signo. Muchos proveedores cobran por tokens de entrada y de salida.

    Mira tu texto partido en fichas

    Aproximación educativa: cada modelo tiene su propio tokenizador y los números reales pueden variar.

    Simulador de costos

    Tarifas hipotéticas en USD por millón de tokens. No son la cotización de un modelo real: para proyectos reales revisa la página oficial de precios.

    Costo por solicitudUS$ 0.002000
    Costo total estimadoUS$ 0.2000

    No incluye herramientas externas, impuestos, almacenamiento ni modos especiales.

    • Envía solo el contexto relevante.
    • No repitas información innecesaria.
    • Pon un límite razonable de salida (max_output_tokens).
    • Elige el modelo según la complejidad: clasificar o resumir no siempre necesita el más avanzado.
    • Reutiliza resultados cuando sea apropiado.
